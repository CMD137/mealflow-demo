# 下单流程

## 如何下单

1. 打开用户端 App，登录后选择商家与菜品。
2. 加入购物车或直接结算，选择优惠券（可选）。
3. 高峰期商家产能已满时，系统会自动进入排队，生成排队票据。
4. 排队票据轮到后自动转为正式订单，再进行支付。
5. 支付成功后在商家端等待接单，出餐后即可取餐。

## 排队规则

- 每个商家同时只允许有限数量的订单进入制作（产能上限）。
- 产能已满时新订单进入等待队列，按到达顺序排队。
- 排队期间可以随时查看排名与预计等待时间。

## 常见问题

- 问：下单后多久出餐？答：取决于商家产能与排队人数，一般 15～40 分钟。
- 问：可以修改订单吗？答：订单支付后暂不支持修改，如需变更请取消后重新下单。
